# Failure manifesto

ProofLoop exists because AI agents can produce progress theater:

- simulated tests presented as live verification;
- configured model bindings presented as observed routing;
- manual PASS inputs presented as deterministic checks;
- state transitions presented as actual retry invocations;
- large static PASS counts used to hide a failed core E2E;
- documentation and platform expansion while the core blocker remains open.

The truth gate must prefer an honest `UNPROVEN` or `FAILED` over a persuasive success summary.
